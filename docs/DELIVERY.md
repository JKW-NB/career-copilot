## 验收标准

- 个人数据与合成 Demo 隔离；关键写入只经过 Rust 受信任命令。
- 未确认事实不能进入已确认组合；历史内容不受后续修改影响。
- 最终版本绑定真实 PDF；投递后不可覆盖，登记投递不向外发送申请。
- API Key 不进入数据库、明文配置、日志或前端读取接口。
- 无 Key 时可完成手工链路，界面明确模型尚未连接。
- 每批改动通过相关测试后提交；不因赶进度虚报全部 MVP 已完成。

## 使用路线

1. 打开桌面版，新增职业资产；描述只作背景。
2. 添加具体事实，点击审查；涉及数字或职责时额外核实。
3. 新建岗位，粘贴 JD，并按行填写要证明的能力及重要性。
4. 选择可信事实，确认组合；生成内容草稿，预览后确认就绪。
5. 导出 HTML 并在浏览器打印为 PDF，或把 Markdown 交给外部排版工具。
6. 登记最终 PDF，真实投递后手工创建记录；登记本身不会向外发送申请。
